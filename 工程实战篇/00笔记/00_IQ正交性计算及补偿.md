# IQ正交性计算及补偿

## 什么是 IQ 信号

## 核心概念

- **IQ 信号**（也称为正交信号、复基带信号）是用一对互相正交的分量来表示同一宽带信号的方式：  
  - $I$（In-phase，同相）分量与本振正弦同相；  
  - $Q$（Quadrature，正交）分量与本振余弦（或相差 $90^\circ$ 的正弦）同相。  
- 在数学上，IQ 信号通常表示为一个复信号：  
  $$
  s(t) = I(t) + j\,Q(t)
  $$
  这里的“复数”只是工程表示法，物理世界中仍然是实信号。

## IQ不平衡的影响

- 镜像干扰（Image Interference）

    - 由于 I/Q 不再严格正交，正负频率分量发生“串扰”，目标频点的能量泄漏到其镜像频点（相对于载频关于 0 频率对称的位置）。
    - 谱上表现为本该被抑制的镜像支路升高，镜像抑制度 IMRR（Image Rejection Ratio）下降。

- 星座图畸变
  
    - 等效为对复基带信号施加了一个“非正交、带剪切”的线性变换：不只是旋转和缩放，还会把圆形变为椭圆、产生交叉耦合。
    - 高阶调制时星座点压扁/拉伸，判决门限不再居中。

- DC 与 LO 泄漏相关效应
  
    - 直流偏置叠加在基带，零中频结构上表现为谱线在 0 Hz 处抬高，降低动态范围并干扰载波/定时恢复。
    - 与 I/Q 不平衡耦合后，可能在近零频产生较强伪分量。

## 

## **IQ不平衡如何校正（去除镜像干扰）**

### 问题与目标

- 问题：I/Q 两路因硬件不匹配产生的幅度失配、相位失配与直流偏置，导致镜像干扰（image），在谱域抬高镜像带，在通信中恶化 BER/EVM，在雷达中产生“负多普勒/零频”伪目标。
- 目标：在数字域对接收的 I/Q 基带信号进行补偿，使补偿后 I/Q 恢复正交、等功率、零相关，镜像显著抑制。

---

### 信号模型与不平衡参数

设原始理想（目标）基带为
- $I'(t) = A \cos\theta$
- $Q'(t) = A \sin\theta$

受不平衡后观测到
- $I(t) = A \cos\theta + \gamma$
- $Q(t) = (1+\varepsilon) A \sin(\theta + \phi) + \kappa$

参数含义：
- $\varepsilon$：幅度失配因子（Q 相对 I 的增益误差）
- $\phi$：相位失配（I/Q 偏离 90° 的误差）
- $\gamma, \kappa$：I/Q 直流偏置（DC）

目标：由观测 $(I, Q)$ 估计 $\varepsilon, \phi, \gamma, \kappa$，构造线性变换把 $(I, Q)$ 还原为 $(I', Q')$。

---

### 步骤总览

1) 去直流偏置（估计并扣除 $\gamma, \kappa$）  
2) 基于二阶统计量估计幅度与相位失配 $(\varepsilon, \phi)$  
3) 构造 2×2 线性校正矩阵 $P$ 并变换  
4) 重组输出复基带，验证镜像抑制效果

---

### 1) 去直流偏置

- 估计直流：
  $$
  d_i = \frac{1}{N}\sum_{n=0}^{N-1} I[n], \quad d_q = \frac{1}{N}\sum_{n=0}^{N-1} Q[n]
  $$
- 去 DC：
  $$
  \tilde I = I - d_i, \quad \tilde Q = Q - d_q
  $$

这一步抑制零频分量，有助于后续统计估计的稳定性。

---

### 2) 二阶统计量估计幅度与相位失配

期望性质（理想目标信号的统计先验）：
- $E\{I'(n)Q'(n)\} = 0$（正交、零相关）
- $E\{I'^2(n)\} = E\{Q'^2(n)\}$（等功率）

对去 DC 后的观测信号 $(\tilde I, \tilde Q)$，在忽略 DC 的前提下有关系：
- $E\{\tilde I^2\} = E\{I'^2\}$
- $E\{\tilde Q^2\} = (1+\varepsilon)^2 E\{Q'^2\}$
- $E\{\tilde I \tilde Q\} = -(1+\varepsilon)\sin\phi \, E\{I'^2\}$

据此可估计：
$$
\varepsilon = \sqrt{\frac{E\{\tilde Q^2\}}{E\{\tilde I^2\}}} - 1
$$
$$
\phi = -\arcsin\left(\frac{E\{\tilde I \tilde Q\}}{\sqrt{E\{\tilde I^2\} \, E\{\tilde Q^2\}}}\right)
$$

实践要点：
- 用足够长的样本窗口估计期望，或使用滑动平均、Welch 等提高稳健性。
- 低 SNR 或多载波时，建议在导频/空时区间内估计或做频率选择性建模（见“扩展建议”）。

---

### 3) 构造线性校正矩阵

为实现
$$
\begin{bmatrix} I' \\ Q' \end{bmatrix}
= P \left( \begin{bmatrix} I \\ Q \end{bmatrix} - \begin{bmatrix} \gamma \\ \kappa \end{bmatrix} \right)
$$

在文中可推出
$$
P =
\begin{bmatrix}
1 & 0 \\
\tan\phi & \dfrac{1}{(1+\varepsilon)\cos\phi}
\end{bmatrix}
$$

解释：
- 第一行把 I 直接映射为目标 $I'$（在该推导框架下 $a_{11}=1, a_{12}=0$）。
- 第二行用 $\tan\phi$ 和 $\frac{1}{(1+\varepsilon)\cos\phi}$ 对 Q 进行“去幅差+去相位耦合”的线性纠正，恢复正交与等功率特性。

应用：
- 先对输入向量去 DC，再左乘 $P$ 得到校正的 $(I', Q')$。

---

### 4) 输出与验证

- 复基带重组：`s_corr = I' + j·Q'`（或按你系统定义的 I+jQ/ Q+jI）
- 验证方式：
  - 频谱：镜像带功率应显著下降，IMRR 提升。
  - 统计：检查补偿后是否满足 $E\{I'Q'\}\approx 0$，$E\{I'^2\}\approx E\{Q'^2\}$。
  - 星座：星座图由椭圆/剪切趋向规则分布，EVM 改善。

---

### 参考 MATLAB 示例

```matlab
%% IQ imbalance compensation demo
% 功能:
% 1) 构造带有 I/Q 不平衡与直流偏置的测试信号
% 2) 采用二阶统计量估计幅度失配 (epsilon) 与相位失配 (phi)
% 3) 去直流并构建 2x2 线性校正矩阵进行补偿
% 4) 对比补偿前后：时域波形、IQ 相图（星座/利萨如）、频谱（镜像抑制）

clc; clear; close all;

%% -----------------------------
% 参数配置
% ------------------------------
fs  = 20e6;          % 采样率 [Hz]
fc  = 2.5e6;         % 基带测试音频率（可理解为基带单音）[Hz]
T   = 1e-4;          % 信号时长 [s]，样本数越多统计越稳定
t   = 0:1/fs:T-1/fs; % 时间向量

% 设定 I/Q 不平衡与直流偏置（用于模拟）
phi_deg = 10;        % 相位失配（度）。I/Q 偏离 90° 的误差量
epsilon  = 0.3;      % 幅度失配因子（Q 相对 I 的增益误差），例如 0.3 => Q 增益大 30%
di       = 0.2;      % I 路直流偏置
dq       = -0.15;    % Q 路直流偏置

% 随机噪声级（可调，用于更接近实测）
snr_dB   = 40;       % 加性高斯白噪声的 SNR

%% -----------------------------
% 构造理想与失衡 I/Q 信号
% ------------------------------
% 理想的基带 I/Q（以同频正交余弦为例）
I_ideal = cos(2*pi*fc*t);
Q_ideal = sin(2*pi*fc*t); % 与 I 理想正交

% 引入幅度失配 + 相位失配 + 直流偏置
phi_rad = phi_deg*pi/180;              % 转换为弧度
I_raw   = I_ideal + di;                % I 路加 DC
Q_raw   = (1+epsilon)*sin(2*pi*fc*t + phi_rad) + dq; % Q 路增益与相位失配并加 DC

% 合成为复基带（工程习惯：s = I + jQ）
x_raw = I_raw + 1j*Q_raw;

% 加性噪声（可选）
x_noisy = awgn(x_raw, snr_dB, 'measured');
I_meas  = real(x_noisy);
Q_meas  = imag(x_noisy);

%% -----------------------------
% 1) 去直流偏置
% ------------------------------
% 估计直流均值（使用测量的 noisy 信号）
di_hat = mean(I_meas);
dq_hat = mean(Q_meas);

% 去 DC 后的 I/Q
I0 = I_meas - di_hat;
Q0 = Q_meas - dq_hat;

%% -----------------------------
% 2) 估计幅度与相位失配 (epsilon, phi)
%    基于二阶统计量的无监督估计
%    假设目标信号满足: E{I'Q'}=0, E{I'^2}=E{Q'^2}
% ------------------------------
EII = mean(I0 .* I0);
EQQ = mean(Q0 .* Q0);
EIQ = mean(I0 .* Q0);

% epsilon 估计：相对功率差的平方根
epsilon_hat = sqrt(max(EQQ, eps)/max(EII, eps)) - 1;

% phi 估计：由相关系数决定（取反正弦）
rho = EIQ / sqrt(max(EII*EQQ, eps));
rho = max(min(rho, 1-1e-12), -1+1e-12); % 数值夹紧，避免超出定义域
phi_hat = -asin(rho);                    % [rad]

%% -----------------------------
% 3) 构造校正矩阵并补偿
%    P = [ 1,                 0;
%          tan(phi),  1/((1+epsilon)*cos(phi)) ]
% 作用：对 Q 做去耦合与等幅处理，使 I/Q 重新正交、等功率
% 注：先去 DC，再线性变换
% ------------------------------
P = [ 1,                 0;
      tan(phi_hat),  1/((1+epsilon_hat)*cos(phi_hat)) ];

IQ0    = [I0; Q0];
IQcorr = P * IQ0;   % 应用线性校正

I_corr = IQcorr(1, :);
Q_corr = IQcorr(2, :);
x_corr = I_corr + 1j*Q_corr;

%% -----------------------------
% 4) 评估与可视化
%    新增：补偿前后 IQ 对比图（时域与相图）
%    频谱对比：观察镜像抑制
% ------------------------------

% 4.1 打印估计结果
fprintf('--- Estimated imbalance ---\n');
fprintf('epsilon_hat = %.4f (true: %.4f)\n', epsilon_hat, epsilon);
fprintf('phi_hat     = %.4f rad (%.2f deg), true: %.4f rad (%.2f deg)\n', ...
        phi_hat, phi_hat*180/pi, phi_rad, phi_deg);

% 4.2 补偿前后的时域波形对比（I/Q 分别绘制）
Nshow = min(400, numel(t)); % 仅展示前 Nshow 点，图像更清晰

figure('Name','Time-domain I/Q comparison','Color','w','Position',[100 100 1200 600]);
subplot(2,1,1);
plot(t(1:Nshow)*1e6, I_meas(1:Nshow), 'r-', 'LineWidth', 1); hold on;
plot(t(1:Nshow)*1e6, Q_meas(1:Nshow), 'b-', 'LineWidth', 1);
grid on; xlabel('Time [\mus]'); ylabel('Amplitude');
title('I channel: before vs after correction');
legend('Before (I_{meas})','After (I_{corr})');

subplot(2,1,2);
plot(t(1:Nshow)*1e6, I_corr(1:Nshow), 'r-', 'LineWidth', 1); hold on;
plot(t(1:Nshow)*1e6, Q_corr(1:Nshow), 'b-', 'LineWidth', 1);
grid on; xlabel('Time [\mus]'); ylabel('Amplitude');
title('Q channel: before vs after correction');
legend('Before (Q_{meas})','After (Q_{corr})');

% 4.3 补偿前后的 IQ 相图（利萨如/星座风格）
% 为了更清晰，随机抽样一部分点
rng(1);
idx = randperm(numel(I_meas), min(20000, numel(I_meas)));

figure('Name','IQ Lissajous / Constellation comparison','Color','w','Position',[200 200 1200 500]);
subplot(1,2,1);
plot(I0(idx), Q0(idx), '.', 'Color',[0.85 0.2 0.2], 'MarkerSize', 4); grid on; axis equal;
xlabel('I_0'); ylabel('Q_0'); title('Before correction (after DC removal)');
% 椭圆/剪切形状意味着存在不平衡
subplot(1,2,2);
plot(I_corr(idx), Q_corr(idx), '.', 'Color',[0.2 0.3 0.9], 'MarkerSize', 4); grid on; axis equal;
xlabel('I_{corr}'); ylabel('Q_{corr}'); title('After correction');
% 期望点云更接近圆形/标准正交

% 4.4 频谱对比（Welch PSD，观察镜像分量）
nfft = 4096;
figure('Name','Spectrum (Welch PSD) comparison','Color','w','Position',[150 150 1200 500]);
subplot(1,2,1);
pwelch(x_noisy, hamming(1024), 512, nfft, fs, 'centered'); grid on;
title('Before correction (centered PSD)');
ylabel('PSD [dB/Hz]');

subplot(1,2,2);
pwelch(x_corr,  hamming(1024), 512, nfft, fs, 'centered'); grid on;
title('After correction (centered PSD)');
ylabel('PSD [dB/Hz]');

%% -----------------------------
% 5) 简单数值验证：统计特性是否恢复
% ------------------------------
EII_corr = mean(I_corr.*I_corr);
EQQ_corr = mean(Q_corr.*Q_corr);
EIQ_corr = mean(I_corr.*Q_corr);
IMRR_est_before = 10*log10( (abs(EII)+abs(EQQ)) / (2*abs(EIQ)+eps) ); % 粗略镜像抑制 proxy
IMRR_est_after  = 10*log10( (abs(EII_corr)+abs(EQQ_corr)) / (2*abs(EIQ_corr)+eps) );

fprintf('--- Statistical checks ---\n');
fprintf('Before: E{I0*Q0}=%.3e, E{I0^2}=%.3e, E{Q0^2}=%.3e\n', EIQ, EII, EQQ);
fprintf('After : E{Ic*Qc}=%.3e, E{Ic^2}=%.3e, E{Qc^2}=%.3e\n', EIQ_corr, EII_corr, EQQ_corr);
fprintf('Proxy IMRR [dB]  -> Before: %.2f  |  After: %.2f\n', IMRR_est_before, IMRR_est_after);

%% 结束
% 说明：
% - 上述 IMRR_est_* 是基于相关项的粗略 proxy，只用于演示改善程度。
% - 实际系统可用更准确的镜像功率测量方法（例如频域在镜像带积分）。
```

说明：
- 例子用单音演示，实测数据流程相同：先去 DC，再统计估计 $\varepsilon,\phi$，最后乘以 $P$。
- 对于宽带/多子载波，可对每个频点或子载波分别估计，或采用频率选择性的 $P(f)$。

---

### 实施细节与注意事项

- 样本量：为保证统计量收敛，建议每次估计使用足够长的样本窗口；对非平稳场景采用滑动窗口/指数加权。
- 饱和/削顶：对强信号注意 ADC 削顶会污染统计量，可做前置检验或剔除异常样本。
- 噪声与干扰：低 SNR 时估计会有偏差，可在导频时隙估计或先做粗滤波提升 SNR。
- 坐标约定：部分系统定义复基带为 $s=I+jQ$ 或 $s=Q+jI$，请与本振路由与后续处理保持一致。
- 数值稳健：当 $\cos\phi$ 逼近 0（极端相位失配）时，矩阵元素放大；实际硬件通常不会到如此极端，但实现中应做阈值/夹紧保护。
- 低 IF/直流：零中频架构对 DC 更敏感，务必先做 DC 去除；若存在随时间漂移的 DC，需周期性更新。
- 校正顺序：先 DC，后 $\varepsilon,\phi$；最终再做常规的频偏、相位跟踪等同步环路。

---

### 扩展建议（超出文中基本方法）

- 频率选择性不平衡：对宽带系统，$\varepsilon(f), \phi(f)$ 随频变化。可用子带分解、OFDM 子载波导频估计，或拟合 FIR/IIR 复值校正滤波器实现频域补偿。
- 自适应算法：在时变环境用 LMS/RLS 或基于最大似然/EM 的盲校准，持续更新 $\varepsilon,\phi$。
- 校准与合规：发射端也可用同法减少镜像泄漏/邻道泄漏以满足 ACLR/谱掩模。

---

### 小结

- 用统计先验 $E\{I'Q'\}=0$、$E\{I'^2\}=E\{Q'^2\}$ 估计 $\varepsilon,\phi$，再构造矩阵
  $$
  P=\begin{bmatrix}
  1 & 0 \\
  \tan\phi & \dfrac{1}{(1+\varepsilon)\cos\phi}
  \end{bmatrix}
  $$
  对去 DC 的 $(I,Q)$ 进行线性变换，可有效抑制镜像干扰。
- 该方法计算量小、实现简单，适合通信与雷达的在线数字补偿，实际中应结合窗口化估计与鲁棒性处理确保稳定收敛。
